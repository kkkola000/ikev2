# IKEv2 VPN для Ubuntu 24.04

`ikev2-setup.sh` разворачивает IKEv2 VPN-сервер на базе [strongSwan](https://strongswan.org/)
(современный `swanctl`/`charon-systemd`) одной командой и выдаёт готовые профили
для клиентов.

- Сервер подтверждает подлинность сертификатом: собственный CA или бесплатный Let's Encrypt.
- Пользователи входят по логину и паролю (EAP-MSCHAPv2), дополнительные программы
  на клиентах не нужны.
- Работают встроенные клиенты Windows 10/11, macOS, iOS/iPadOS, Android (приложение
  strongSwan или встроенный IKEv2) и Linux (NetworkManager).
- Для каждого пользователя создаются профили: `.mobileconfig` (Apple), `.sswan` (Android),
  PowerShell-скрипт для Windows и README с инструкцией.
- Настраиваются NAT, IP forwarding, MSS clamping, IKE-фрагментация и MOBIKE.
  ESP всегда инкапсулируется в UDP 4500, поэтому VPN проходит через NAT и
  файрволы, которые блокируют протокол ESP.
- Правила файрвола живут в отдельных цепочках `IKEV2-*` и уживаются с UFW и Docker.
- Если у сервера есть IPv6, клиенты получают IPv6 через туннель (NAT66, ULA-подсеть).
- Команды для управления пользователями: добавить, удалить, сменить пароль, статус.

## Требования

- Ubuntu 24.04 LTS (x86_64 или arm64), доступ root.
- VPS на KVM/Xen/VMware или физический сервер. В контейнерах OpenVZ/LXC IPsec обычно
  не работает.
- Открытые входящие порты **UDP 500 и UDP 4500**. Если у хостинга есть внешний файрвол
  (security group), откройте их там.
- Для Let's Encrypt: домен с A-записью на сервер и свободный порт **TCP 80**
  (certbot запускается в режиме standalone и при продлении тоже).

## Быстрый старт

```bash
git clone https://github.com/kkkola000/ikev2.git
cd ikev2
sudo bash ikev2-setup.sh
```

Скрипт ничего не спрашивает. Без параметров он сам определяет публичный IP,
выпускает сертификат собственного CA и создаёт пользователя `vpnuser` со случайным
паролем. В конце выводятся логин, пароль и путь к профилям
(`/root/ikev2-clients/<пользователь>/`).

Скачать профили на свой компьютер:

```bash
scp -r root@АДРЕС_СЕРВЕРА:/root/ikev2-clients/ .
```

### Примеры

```bash
# По IP-адресу, собственный CA
sudo bash ikev2-setup.sh --host 203.0.113.10 --user alice

# По домену с сертификатом Let's Encrypt
sudo bash ikev2-setup.sh --host vpn.example.com --letsencrypt --email admin@example.com --user alice
```

### Параметры `install`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--host АДРЕС` | публичный IPv4 | Домен или IPv4, по которому подключаются клиенты |
| `--letsencrypt` | — | Сертификат Let's Encrypt (нужен домен и порт 80/tcp) |
| `--self-signed` | ✓ | Собственный центр сертификации (CA) |
| `--email EMAIL` | — | Email для уведомлений Let's Encrypt |
| `--user ИМЯ` | `vpnuser` | Первый пользователь |
| `--password ПАРОЛЬ` | случайный | Пароль первого пользователя |
| `--dns СПИСОК` | `1.1.1.1,1.0.0.1` | DNS-серверы для клиентов, через запятую |
| `--pool CIDR` | `10.10.10.0/24` | Подсеть адресов клиентов (частная, /16–/29) |
| `--ipv6` / `--no-ipv6` | авто | IPv6 в туннеле |

`install` можно запускать повторно: например, чтобы сменить DNS или адрес сервера.
CA, пользователи и их пароли при этом сохраняются, а профили пересоздаются.

## Управление

После установки скрипт копируется в `/usr/local/sbin/ikev2-vpn`:

```bash
sudo ikev2-vpn add-user bob            # добавить пользователя (пароль будет сгенерирован)
sudo ikev2-vpn add-user bob 'Пароль'   # ... или задать свой
sudo ikev2-vpn passwd bob              # сменить пароль (активные сессии будут разорваны)
sudo ikev2-vpn del-user bob            # удалить пользователя и разорвать его подключения
sudo ikev2-vpn list-users              # список пользователей (кто сейчас в сети)
sudo ikev2-vpn status                  # состояние служб и активные подключения
sudo ikev2-vpn profiles [bob]          # пересоздать клиентские профили
sudo ikev2-vpn uninstall [--purge]     # удалить VPN (--purge удалит и пакеты strongSwan)
```

Требования к данным:

- имя пользователя: латиница, цифры и символы `. _ @ -`;
- пароль: от 8 до 128 печатных ASCII-символов, без `"` и `\`.

## Подключение клиентов

Логин и пароль лежат в `README.txt` в каталоге пользователя. «Адрес сервера» и
«удалённый ID» — это значение `--host`.

### iPhone, iPad, Mac

Передайте на устройство файл `<пользователь>.mobileconfig` (AirDrop, почта, Файлы) и
установите его:

- iOS: «Настройки → Профиль загружен → Установить»;
- macOS: «Системные настройки → Конфиденциальность и безопасность → Профили».

Сертификат CA и пароль уже внутри профиля, поэтому передавайте этот файл
только по защищённому каналу.

### Android

**Приложение strongSwan** (рекомендуется): установите
[strongSwan VPN Client](https://play.google.com/store/apps/details?id=org.strongswan.android)
(есть и в F-Droid), затем в меню выберите «Импорт VPN-профиля», укажите файл
`<пользователь>.sswan` и введите пароль при подключении.

**Встроенный клиент** (Android 11+): «Настройки → Сеть → VPN → Добавить»,
тип **IKEv2/IPSec MSCHAPv2**.

- Если сервер работает на собственном CA, сначала установите `ikev2-vpn-ca.crt`:
  «Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС».
- Если сертификат от Let's Encrypt, дополнительные сертификаты не нужны.

### Windows 10/11

Скопируйте `<пользователь>-windows.ps1` на компьютер и выполните его в PowerShell
**от имени администратора**:

```powershell
powershell -ExecutionPolicy Bypass -File .\alice-windows.ps1
```

Скрипт импортирует сертификат CA (если он нужен), создаст подключение и включит в нём
стойкие алгоритмы шифрования. После этого откройте «Параметры → Сеть и Интернет → VPN»,
выберите подключение и введите логин и пароль.

<details>
<summary>Ручная настройка без скрипта</summary>

1. Собственный CA: откройте `certlm.msc` и импортируйте `ikev2-vpn-ca.crt` в
   «Доверенные корневые центры сертификации» **локального компьютера**.
2. По умолчанию Windows предлагает только устаревшую DH-группу 2, а сервер её не
   принимает. Разрешите AES-256 и DH-группу 14 и перезагрузите компьютер:
   ```
   reg add HKLM\SYSTEM\CurrentControlSet\Services\RasMan\Parameters /v NegotiateDH2048_AES256 /t REG_DWORD /d 1 /f
   ```
3. «Параметры → Сеть и Интернет → VPN → Добавить VPN»:
   тип «IKEv2», вход «Имя пользователя и пароль».
</details>

### Linux

Установите `network-manager-strongswan` и создайте VPN-подключение «IPsec/IKEv2 (strongswan)»:

- сервер: адрес сервера;
- сертификат: `ikev2-vpn-ca.crt` (для Let's Encrypt — системные);
- аутентификация: EAP (логин и пароль);
- включите «Request an inner IP address».

## Что устанавливается и настраивается

| Путь | Назначение |
|---|---|
| `/etc/swanctl/conf.d/ikev2-vpn.conf` | Подключение и пулы адресов |
| `/etc/swanctl/conf.d/ikev2-vpn-secrets.conf` | Пароли пользователей (генерируется из `/etc/ikev2/users`) |
| `/etc/swanctl/x509*/ikev2-vpn-*`, `/etc/swanctl/private/ikev2-vpn-server.pem` | Сертификаты и ключ сервера |
| `/etc/ikev2/` | Параметры установки, база пользователей, ключ CA (только для root) |
| `/root/ikev2-clients/` | Клиентские профили |
| `/etc/sysctl.d/60-ikev2-vpn.conf` | IP forwarding |
| `/usr/local/sbin/ikev2-vpn-firewall`, `ikev2-vpn-firewall.service` | Правила iptables (NAT, forward, MSS) |
| `/etc/strongswan.d/ikev2-vpn.conf` | Список плагинов для утилит `swanctl`/`pki` |
| `/etc/letsencrypt/renewal-hooks/deploy/ikev2-vpn.sh` | Подхватывает продлённый сертификат Let's Encrypt |

Службы: `strongswan.service` (charon-systemd) и `ikev2-vpn-firewall.service`.

Криптография:

- IKE: AES-GCM и AES-CBC, SHA-2 (SHA-1 оставлен для совместимости),
  DH: Curve25519, ECP-256/384, MODP-2048/3072;
- ESP: AES-GCM, ChaCha20-Poly1305, AES-CBC.

Слабые группы (MODP-1024) и 3DES отключены.

## Диагностика

```bash
sudo ikev2-vpn status
sudo journalctl -u strongswan -f          # журнал подключений в реальном времени
sudo swanctl --list-sas                   # активные SA
sudo swanctl --log                        # подробный лог во время подключения
sudo iptables -S IKEV2-INPUT; sudo iptables -t nat -S IKEV2-POSTROUTING
```

Частые проблемы:

- **Клиент не может соединиться, в журнале пусто.** Пакеты не доходят до сервера:
  проверьте UDP 500/4500 во внешнем файрволе хостинга.
- **Windows: ошибка 13801.** Сертификат сервера не доверенный или не совпадает с адресом:
  импортируйте CA в хранилище *локального компьютера* и подключайтесь ровно по тому адресу,
  который указан в `--host`.
- **Windows: ошибка 13868 или «policy match error».** Windows предлагает слабые алгоритмы:
  используйте `.ps1` из профиля или ключ реестра из раздела «Ручная настройка».
- **Подключение есть, а сайты не открываются.** Проверьте, что служба
  `ikev2-vpn-firewall` активна (`systemctl status ikev2-vpn-firewall`), и что подсеть `--pool`
  не пересекается с сетями сервера.
- **Let's Encrypt не выдаёт сертификат.** A-запись домена должна указывать на сервер,
  а порт 80/tcp должен быть открыт и свободен (nginx или apache на время установки
  нужно остановить).

## Удаление

```bash
sudo ikev2-vpn uninstall           # конфигурация, CA, пользователи, правила файрвола
sudo ikev2-vpn uninstall --purge   # то же + пакеты strongSwan
```

Удаление выполняется сразу, без подтверждения.
